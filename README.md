# Space to Rise — sitio web

Sitio estático (HTML/CSS/JS) de spacetorise.com, reconstruido por Clicalto.

- `build.py` genera las páginas (`python3 build.py`) a partir del contenido y los partials.
- `assets/` — imágenes, fuentes (Cyntho Next), video RTT, datos de la tienda (`assets/data/products.json`).
- Despliegue: Vercel (estático, `vercel.json` con URLs limpias y redirecciones).
